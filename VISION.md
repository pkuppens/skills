# Vision

We are a virtual SDLC services company: agents, teams, and projects use this curated catalog of skills to deliver software end‑to‑end. The catalog provides canonical, practice‑oriented skills for every SDLC stage (ideation, requirements, architecture, design, implementation, testing, deployment, operations) and curated bundles for common project intents (e.g., greenfield services, migrations, hardening).

Skills are authored or selected with provenance, licensing, example usages, and configuration guidance so teams can adopt them safely and adapt them to project constraints. The library supports feedback‑driven refinement and project‑specific tuning while preserving traceability and changelogs.

Governance enforces a clear canonical / vendor / derivative boundary and prioritizes reference‑first contributions to avoid duplication. The strategy→skill pipeline in [skills/SKILL_TREE.md](skills/SKILL_TREE.md) composes analysis, clarification, architecture, and validation into practical workflows, and curated bundles reduce adoption friction ([docs/curated-skill-selection.md](docs/curated-skill-selection.md)).

Any agent that implements the [Agent Skills specification](https://agentskills.io/specification) can consume this library without vendor lock‑in. This repo is a living, evidence‑driven catalog maintained to make SDLC delivery repeatable, auditable, and adaptable.
