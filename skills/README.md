# `skills/` directory

Agent skills live in subdirectories as `skills/<name>/SKILL.md` per the [Agent Skills specification](https://agentskills.io/specification).

**Install, symlinks, and Skills CLI:** see the [repository README](../README.md).

**Skill index:** [SKILL_TREE.md](SKILL_TREE.md)

**Transfer and contribution:** [`skills-transfer/SKILL.md`](skills-transfer/SKILL.md) (nested [`repo-transfer`](skills-transfer/repo-transfer/SKILL.md) for PRs into this library).

Migration from [`pkuppens/pkuppens`](https://github.com/pkuppens/pkuppens) is tracked in [issue #90](https://github.com/pkuppens/pkuppens/issues/90) and in issues on this repository.
